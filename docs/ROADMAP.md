# Дорожная карта

## v0.1 — Foundation

- Electron/React UI, демо с оригинальным текстом, импорт TTML.
- Независимые часы/синхронизация, пауза, seek в демо, offset, Reduce Motion.
- Windows GSMTC bridge, diagnostics и системные команды при доступных capability.
- Типы будущего анализа/эффектов, тесты и Windows CI.
- Обязательная оставшаяся валидация: реальные сценарии Windows 11 + Apple Music из WINDOWS_TESTING.md. Без неё интеграция не считается подтверждённой.

## Следующие этапы (в этой версии не реализуются)

1. Проверить разные версии Apple Music/AUMID, устойчивость таймлайна, расширить подтверждённые TTML-профили. Добавить долговременную привязку текстов к трекам и подпись дистрибутивов.
2. Подключать только официальные или лицензированные источники синхронизированных текстов через LyricsProvider.
3. Контекстный локальный ru/en SemanticAnalyzer с объяснимыми назначениями и ручными правками. Не подменять его простым сопоставлением ключевых слов.
4. Canvas/WebGL эффекты Fire/Rain/Cold/Fall/Love/Smoke с общим playback time, отменой устаревшей работы, budget качества и Reduce Motion.
5. Редактор назначений и таймлайна, хранение EffectTimeline по песне; компактный режим и настраиваемые виджеты.
6. Отдельно оценить законность и техническую доступность библиотеки/поиска/альбомов Apple Music, других сервисов, локального аудио и дополнительных возможностей воспроизведения. Spotify, MP3/FLAC, эквалайзер и кроссфейд не входят в v0.1 и не обещаются текущим интерфейсом.
